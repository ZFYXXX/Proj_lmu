# 实验定义与解释范围

W 是解码后的 16 kHz 波形；F 是 Mel 前端；C 是首个音频 Transformer block 输入；E_l／E_L 是中间／最后编码层；P_in 是原生平均池化和 LayerNorm 后、线性 projector 前；P_out 是 projector 输出。完整 B 固定为同一批 5,000 道 MMSU-final 题。

**本目录所有实验保持模型原生 token 数，不执行额外 token 压缩。** 已删除 Matched-budget Token Merge Analysis。音高、包络、停顿入口只读原始属性与原始任务表现。

## 当前 10 个入口

## 数值和统计约定

1. W 功率谱使用 25 ms Hann、10 ms hop、400 点 FFT，单边功率的非 DC／Nyquist 项乘 2；每题归一化后汇总。零能量音频不伪造 roll-off 或 F0。
2. 波形滤波采用偶对称延拓、实 FFT 零相位增益、默认 200 Hz raised-cosine 过渡带，返回原样本数。RMS 匹配独立列出，不裁剪振幅；记录实际移除比例、gain 和 peak。
3. 等能量条件按线性功率求衰减量；最弱频带近零会使共同干预近零。移除比例 ≤1e-6 记为退化，仍保留完整 B 评分。
4. 表示时间谱按原生 chunk 计算 raw／去均值版本，汇总 16 个归一化频率区间。C／E_l 名义步长 20 ms、Nyquist 25 Hz；P_in／P_out 为 40 ms、12.5 Hz。hidden 维度不当作 Hz。
5. ACF／RMS 为 40 ms 窗、10 ms hop，F0 搜索 50–800 Hz、周期性阈值 0.6。至少 5 个有效 F0 帧才报告音高中位数和 IQR。活动阈值为最大 RMS 以下 40 dB、下限 −80 dB，并排除近零幅度。
6. 属性三分位点仅使用唯一音频的原始输入，不读取 QA 分数；同值不拆分，恒定／缺失值单列。组内准确率按题计权，CI 按音频聚类 bootstrap；细任务、时长和原 token 数细分只作描述性检查。
7. 条件使用同一批完整题目、greedy 生成、逐题轮换执行顺序。原题答案不改，干预分数诊断原任务信息保留，不是对改变后音频重新标注。默认 1,000 次聚类 bootstrap；区间未做多重选择校正。
8. 所有条件的表示漂移直接在原生网格计算；长度不同即拒绝。没有 token 合并、广播替换或 token-mass attention 调整。

## Spectral Redundancy 的证据范围

0／7 描述能量分布；1／3／7／9 通过等带宽、RMS、等移除能量和分辨率控制检验任务必要性；2 检验频带交互，8 检验保长度时间平滑。删除高频后低损伤只支持当前模型和 MMSU 对该输入变化的容忍性，**当前套件不再检验 token 可合并性或加速**。

lag 相似度、时间局部性、边界敏感性均已移除。包络／载波嵌合、WORLD 重合成、跨带错位、缺失基频和声音纹理重合成也不在本次实现中。

## 共享推理

`all` 对 10 个入口的完整操作参数去重；原始基线每题一次。实验 1 与 3 共享对应删带条件，波形恒等共享；4–6 直接共用原始答案，无额外推理。RMS／自然幅度／等移除能量仍为独立条件。

默认 **56 个唯一干预＋原始基线＝285,000 次生成**。独立运行各入口为 425,000 次，共享节省 140,000 次。`analysis.json` 保存入口到共享条件的映射。完整覆盖检查通过后输出 10 份报告；它们不是 10 次独立重复实验。
