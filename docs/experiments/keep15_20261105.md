# Qwen2.5-VL-7B：逐图保留 15%（旧权重预算泛化）

## 固定定义

- 原始 N 为实际送入压缩器的 post-merger 视觉 Token 数，不是 ViT patch 数。
- 所有压缩组统一 `K=min(N,max(1,round(0.15*N)))`，Python round，半整数取偶数。
  这是保留 15%、约删除 85%，不是删除 15%；整数舍入后实际比例不必恰为 15%。
- 不额外限制 K128，也不改变原生动态分辨率、任务 prompt、生成和评分接口。
- Dense 不压缩。通过已有协议/数据核验的 dense 结果可复用；缺失基线才调度推理。
- 每图预算固定由 N 决定，不根据任务得分调节，也不是输入复杂度自适应的动态预算。

## 不先重训

MLP 逐 Token 共享参数，不要求序列固定为 128；原权重可直接处理不同簇数。
因此先固定所有 checkpoint，测量 K128 训练权重在 15% 预算下的泛化。
这不保证性能持平，也不能当成已完成比例适应训练的模型。
重要性评分仍复用原 K128 soft-mask 标定；本轮不重标定、不修改评分器训练 spec。
保护策略仍使用原 minimum_anchor=20（最终不超过实际 K），不额外修改保护规则。

新 MLP 使用仓库已有 `artifacts/checkpoints/r1_balanced2560_step320`，两台机器统一
通过 profile 的 checkpoint 角色解析。旧权重、K128 方法目录、实验结果均不覆盖。
新别名 `_r15` 与旧结果分离，旧 K128 的压缩组不能误导入；Dense 可按原规则复用。
MMTok 显式启用 round，未指定的新/旧调用仍保留其原 floor 规则。
