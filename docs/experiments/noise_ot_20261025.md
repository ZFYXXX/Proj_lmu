# Independent noise-gate / OT experiments

Implement the user's noise-gate and OT request as two separate changes. The
previously discussed 96-native + 32-local-pool branch is deferred, not silently
combined. No existing selector architecture, checkpoint format/hash contract,
historical result or frozen execution worktree is overwritten. No Git commits.

## Controls and hypotheses

Both arms use Qwen2.5-VL-7B, BF16/eager, native dynamic resolution, K=min(128,N),
the current native prompts/scorers/greedy generation/repetition penalty 1.05.
Reuse the completed question-context selector as the primary quality control;
reuse dense/image-context/old-MLP as secondary context, not timing comparisons.

1. **VP-noise training:** same architecture, initial visual step320 warm start,
   zero context branch, original 2560 training images/order, optimizer, seed42,
   320 additional steps and CE + .5 teacher KL + annealed soft-mask BCE. Only
   replace `alpha*x` by `sqrt(alpha)*x + sqrt(1-alpha)*epsilon`, epsilon~N(0,I).
   The training sequence remains full length. No denoising network, temperature
   change, new supervision, or OT. Deployment is the UNCHANGED hard Top-K gather
   of original contents/positions. Near-endpoint square roots use a 1e-6 floor
   for bounded derivatives while exact zero/one forward endpoints are retained.
   Resume pins this numerical choice in the source hash and restores noise RNG.
   Gate diagnostics' applied_mass means sum(alpha), NOT a sum of amplitudes.
2. **OT inference:** freeze the EXISTING trained question-context weights. The
   last answer-free user text embedding tokens act as provisional query atoms;
   they are not parsed semantic entities. Use cosine cost C[t,n]=1-cos(q_t,x_n).
   Solve min `<P,C> + eps sum P(log P-1) + rho KL(P.T 1 || uniform(N))`, with
   `P 1=uniform(T)`, eps=.05, rho=.1. Log-domain semi-unbalanced Sinkhorn,
   tolerance1e-5, max200 iterations, fail rather than skip unconverged samples.
   Final ranking is z(scorer logits) + 1.0*z(log column mass), std floor1e-6;
   hard K selection has source-index tie-break and source-order serialization.
   `ot_weight=0` EXACTLY recovers the old ranking. Native content, visual M-RoPE,
   text positions and cache lifecycle are unchanged. No pooling or trained OT.

OT may allocate mass to different words but column-mass Top-K does NOT guarantee
multi-entity coverage of the final subset. Raw text/visual embeddings may be
poorly aligned. Parameters are fixed before evaluation; no test-set sweep.
The noise interpolation does NOT guarantee covariance preservation for raw
post-merger features, nor does it make noising equal physical deletion.

## Sources and limits

- [DiffPrune](https://arxiv.org/html/2608.01985), section4.3, motivates the noise
  interpolation. Its full pipeline has a separate train-only diagonal-attention
  block and a different scorer. This arm is an isolated adaptation, NOT a full
  reproduction, and a null result cannot reject that paper.
- [Semi-relaxed Sinkhorn](https://arxiv.org/abs/2205.13846) and
  [OTFS](https://arxiv.org/html/2610.27692v1) motivate fixed-source/relaxed-target
  transport. This code does not reproduce OTFS video evidence/DP extraction.
  Fixed marginal rows are verified against an independently optimized small
  primal objective, not only a duplicated Sinkhorn implementation.

## Gates, execution and products

CPU: formula/endpoints, finite scorer gradients and frozen base, reproducible
noise/RNG and exact optimizer restore; OT primal agreement, permutation,
nonconvergence rejection, K budget/ties and weight-zero identity; native Qwen
forward/loss/generate, prompt-only audit, text rotary positions and cache decode.

Run `scripts/train/qwen25_vl/run_noise_ot.py prepare --root NEW --reference OLD`
from a new hash-frozen execution worktree. `pipeline --root NEW --gpu 1` runs
24 real OT smoke requests (8/task), real7B noise4 versus2+2 restore gates,
fixed320-step noise training, 24 trained-noise smoke requests, then six full
cells: ChartQA2500, OCRBench1000, AI2D3088 for each arm. No 500-image dev pass,
no retraining dense/control, no combined arm. GPU0 is not requested. Only own
outputs/cache are writable; shared model/data remain read-only. If GPU1 becomes
busy, queue before the next launch; never evict another process.

All task generation and scoring uses `mllm-comp eval`. Each request retains
prediction/native score, indices, original/retained counts, question hash,
runtime/cache checks and OT diagnostics. Final reporting pairs the original
same-task control by exact prompt/target and image fingerprint, 10k image-cluster
bootstrap; this is one training seed, not cross-seed uncertainty. AI2D strict
is primary; leading generated option parsing is not first-token-logit argmax.
All phases fail closed, preserve logs, resume only hash-matching artifacts, and
never treat failed/missing requests as completed.

## Reporting-only recovery amendment

The first full OT ChartQA cell completed, but the original report reader
incorrectly expected `run` fields in schedule cells marked `action: evaluate`.
Those paths actually live in `eval/full_selective/<method>/<task>/complete.json`.
`noise_ot_reporting.py` now resolves those completion records in memory and
checks source, evaluation-plan hash, config hash, method, dataset and count.
It never rewrites the historical plan or prediction files.

For the already frozen v1 experiment, launch `resume_noise_ot.py --root RUN
--gpu 1`. It imports the ORIGINAL execution worktree, validates its original
source/protocol, and applies only the separately hashed reporting read adapter.
It first successfully reports the completed cell before launching any GPU job.
The previous failed manifest and amendment hashes are retained under
`resume_attempts/`. Completed training, restore gates, smoke cells and OT
ChartQA are reused; only the five missing full evaluations are launched. No
model-code/checkpoint changes, retraining, or automatic Git commits are involved.
